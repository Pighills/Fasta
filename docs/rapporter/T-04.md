# T-04 · L1 – typsnittet lokalt – rapport

Claude Code 2026-09-26, gren `t04-typsnitt-lokalt`.

**Ändrat:** Outfit levereras från appen själv i stället för från Google.
- `fonts/outfit-latin.woff2`: variabel fil (vikt 100–900, teckenuppsättning latin med å, ä, ö) ur npm-paketet `@fontsource-variable/outfit` 5.3.0, hämtat med `npm pack` (inga skript körda). Licens: `fonts/OFL.txt` (SIL OFL 1.1).
- `css/fonts.css` (ny): `@font-face` "Outfit", `font-display: swap`, vikt 300–800. `css/styles.css` orörd.
- `index.html`: Google-länken borttagen; `preload` av fontfilen och `css/fonts.css` före `styles.css`.
- `sw.js`: `./css/fonts.css` och `./fonts/outfit-latin.woff2` i `PRECACHE` (`CACHE` höjs vid publicering).
- `tests/sw.test.mjs`: nytt test att alla filer i `PRECACHE` finns och att fontfilerna är med.

**Storlek:** före 32,3 KB font + 0,9 KB CSS från två Google-servrar (`docs/benchmark/baseline.md`). Efter 32,3 KB font + 0,3 KB CSS från fastatimer.se. Samma mängd data, men inga anslutningar till Google (ingen IP skickas dit) och ett DNS-/TLS-uppslag mindre för nya besökare.

**Testat:**
- `node --test tests/*.test.mjs`: 82 gröna, 1 todo (T-17, löses av T-18).
- 390×844 lokalt: bara `/css/fonts.css` och `/fonts/outfit-latin.woff2` laddas, inga anrop till `fonts.googleapis.com`/`fonts.gstatic.com`. Vikterna 300, 400, 600 och 800 finns (`document.fonts.check`). Inga sådana adresser kvar i appens filer (bara i gamla rapporter under `docs/`).
- Offline: servern stoppad och sidan omladdad → appen startar ur cachen och typsnittet är Outfit.
- Utseende: Timer, Lära, Historik och Profil ser ut som förut (samma typsnitt, samma vikter).

**Inte testat:** riktig telefon; Vercels svar för `.woff2` (kontrolleras i förhandsversionen).

## Det här kan Anton se på datorn
1. Appen ser exakt likadan ut som förut – ingen synlig skillnad är målet.
2. (Frivilligt) I Chrome: F12 → fliken Nätverk → ladda om: inget anrop till "fonts.googleapis.com", i stället `outfit-latin.woff2` från fastatimer.se.
3. Stäng av wifi efter ett besök och ladda om: typsnittet är fortfarande det runda FASTA-typsnittet.

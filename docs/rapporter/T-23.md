# T-23 – dagens check-in på Timer

- Klar på `codex/T-23`, från `lokal/main` med fasta-v41. Inte pushad eller publicerad.
- Timer har kortet Dagens check-in under programkortet, med och utan pågående fasta.
- Rutan sparar/ändrar energi, hunger, sömn, valfri vikt och besvär; ett valt skalvärde kan väljas bort.
- Yrsel visar `CHECKIN_TEXT.besvarYrsel` direkt. Intro, hunger, vikt och vägningsråd återanvänder godkända konstanter ordagrant, med befintliga källor.
- Vägningsval sparas direkt (anges i rutan). Veckovis visar vikt på måndagar eller efter ”Lägg till vikt”; redan sparad vikt visas vid ändring. ”Inte alls” döljer fältet utan att radera sparad vikt.
- Radering kräver bekräftelse. Bara aktuell lokal dag får sparas/raderas. Gamla dialoger vägras om dagens uppgifter har ändrats; befintligt skydd mot andra flikar används.
- Inget nytt dataformat. Ändrat: `timer.js`, `modals.js`, `actions.js`, `styles.css`; nya tester i `checkin-actions.test.mjs`. Ingen ny appfil eller global funktion behövdes.
- Kontroll: `node --check` på ändrade JS-filer; hela testsviten **137 godkända, 0 fel**, varav 5 nya handlings-/dataskyddstester.
- Webbläsare 390×844: tomt formulär, vikt under gränsen, spara/ändra/radera inklusive omladdning, avbryt radering, yrsel, veckoval, daglig vägning, ”Inte alls”, bevarad dold vikt och kortet under pågående fasta. Inga konsolfel.
- Uppmätt: skaltryckytor ≥44×44 px, viktfält 16 px, ingen sidöverströmning. Befintlig dialoghantering för fokus och Escape återanvänds.
- Riktig telefon, installerad PWA, offline och notch ej testade. Dygnsskifte och gamla dialoger testade via automatiska tester, inte genom att ändra enhetens klocka.
- Claude Code höjer cacheversionen vid publicering. Kunskapsbasen ändras inte av Codex; kontrollera vid integration att de använda check-in-texternas *nu*-fält beskriver Timer-rutan.

- ”Radera dagens check-in”, ”Radera dagens check-in? Dagens värden tas bort. Det går inte att ångra.”, ”Avbryt”, ”Radera”.
- ”Fyll i minst en sak.”, ”Ange en vikt mellan 30 och 250 kg.”, ”Det har blivit en ny dag. Stäng rutan och öppna dagens check-in igen.”, ”Uppgifterna har ändrats eller kan inte sparas. Stäng rutan och försök igen.”

## Anton kan se på datorn efter integration
1. Timer → Gör dagens check-in: välj skalvärden och kryssa i Yrsel för att se hjälptexten.
2. I samma ruta: byt vägningsval; viktfältet följer valet. Spara och använd Ändra på Timer.
3. Ändra → Radera dagens check-in: avbryt eller bekräfta raderingen.

Nästa steg: Claude Code granskar T-23 och T-24; T-16 kan göras när T-23 är live enligt kön.

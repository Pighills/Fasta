## Kontrollerat och begränsningar
- Källor och hänvisade avsnitt lästa. Kostnader för Mac/molnbygge och exakt iOS-gräns för väntande notiser är markerade för senare kontroll.
- Appens nuvarande lagring, service worker-registrering och externa typsnitt kontrollerade i koden.
- `git diff --check`: godkänt. `node --test tests/*.test.mjs`: 38 godkända.
- Inga JS-filer ändrade, därmed inget nytt underlag för `node --check`.
- Oförändrad app startade lokalt vid 390×844. Inget Capacitor-bygge eller test på fysisk telefon ingår i en förstudie.
- Kön lämnas till Claude Code att uppdatera enligt protokollet.

## Anton kan läsa på datorn
1. Avsnitt 1–2: hur samma app kan återanvändas och hur data ska flyttas säkert.
2. Avsnitt 3–4: påminnelser och butikernas krav.
3. Avsnitt 5–6: kontoavgifter och föreslagen arbetsordning.
4. Inget syns som ändring inne i appen.

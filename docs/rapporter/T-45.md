# T-45 – Svenskt appnamn och maskable-ikon

Klar på gren `codex/T-45`. Liten ändring, redo för Code-granskning.

- Manifest: exakt beställt svenskt namn och beskrivning, `lang: sv`, vanliga ikoner med `purpose: any`.
- Egen 512×512 maskable-ikon: befintlig bild skalad till 410×410 och centrerad på #0a0a0a. Den cirkulära loggan ligger helt inom säkerhetscirkeln.
- Ikonen tillagd i PRECACHE. Cache-versionen är kvar på fasta-v47 enligt arbetsflödet; Code höjer vid publicering.
- Jämförelse med cirkelbeskärning: `docs/design/T-45/jamforelse.png`.
- Bilden skapad med System.Drawing, inga nya appberoenden.
- `node --check` för sw.js och nya testfilen: grönt. Alla 170 tester gröna.
- Lokal server för rätt arbetskopia på port 3015: appstart i 390×844, inga konsolfel; manifest och ikon öppnade och kontrollerade.
- Faktisk installation på Android/iPhone och olika Android-startskärmar kunde inte testas. Cirkelbeskärning simulerad i jämförelsebilden.
- Ingen ändring av användardata eller appens vyer.
- Kön läses endast av Codex enligt arbetsflödet; Code sätter status vid granskning.

Anton kan kontrollera på datorn:
1. Öppna jämförelsebilden: gammal ikon till vänster, ny till höger med mer marginal.
2. Öppna manifest.json: namnet är FASTA – Periodisk fasta och beskrivningen är svensk.
3. Öppna Timer: samma vy och funktioner som tidigare. Namn/ikon märks först vid installation.

Nästa: Code granskar T-45. Codex T-46 görs i nästa tråd från denna gren.

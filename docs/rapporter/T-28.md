- Status: klar på `codex/T-28`, byggd från `codex/T-27`. Redo för granskning.
- Vid första start visas "Om FASTA" med friskrivningen ordagrant från `juridik.friskrivning`, länken "Integritet och villkor" och "Jag förstår".

- Inget ändrat format i fasta-data, ingen ändring i state/data/backup eller cache-version.

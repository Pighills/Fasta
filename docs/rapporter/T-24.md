# T-24 – trender i Historik

- Klar på `codex/T-24`, byggd på `lokal/t22-checkin-grund`. Inte pushad eller publicerad.
- Ny ruta **Historik → Så har du mått**: 28 dagars energi/hunger/sömn, veckosnitt, antal dagar med besvär.
- Vikt: åtta veckor, vägningar, sjudagarssnitt, målvikt och godkänd text med källa från `CHECKIN_TEXT`.
- ”Inte alls” döljer vikt även i dagdetaljer. Under 18/ätstörning döljer ”kg kvar”; vald vägning kan fortfarande visa mållinjen.
- Dagar öppnar detaljer i rutan; radering kräver bekräftelse och använder T-22:s `removeCheckin` och skydd mot gamla flikar.
- Inga ändringar i lagringsformat eller hälsotexter. Nya knappar använder händelselyssnare.
- Tekniska val: veckosnitt måndag–söndag enligt `weekAverages`, därför märkt ”den här veckan”. Planens formulering ”senaste 7 dagarna” används inte.
- Stapelraden rullas i sidled för 44 px breda tryckytor; senaste dagarna syns först. Vägningar har även en textlista.
- Kontroller: `node --check` för båda ändrade appfilerna; `node --test tests/*.test.mjs`: **137 godkända, 0 fel** (5 nya tester).
- Webbläsare 390×844: appstart, 0/2/10 dagar, med/utan vikt och målvikt, avstängd vägning, under 18, tryckytor och ingen sidöverströmning.
- Testat dagdetaljer, avbruten och genomförd radering av syntetiska testdata; vald dag försvinner och grannens värden finns kvar. Inga konsolfel.
- Riktig telefon, installerad PWA, notch och offline har inte testats. Ny modul kräver PRECACHE vid publicering.
- Integration: bevara T-15:s ändringar i `history.js`. Claude Code lägger till `js/views/trends.js` i PRECACHE och höjer cacheversionen vid publicering (även T-22:s `checkin.js` behövs).

## Anton kan se på datorn efter integration
1. Historik → Så har du mått: dagliga staplar, veckosnitt och besvär.
2. Samma ruta → Vikt: kurva, målvikt och listan ”Visa vägningar som text”. Kräver sparade vägningar.
3. Tryck på en dag: se värden och radera med bekräftelse. Dagens inmatning kommer med T-23.

Nästa steg: Claude Code granskar T-24 tillsammans med T-22/T-15; T-23 kan därefter byggas enligt kön.

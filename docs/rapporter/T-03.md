# T-03 · Fas 1a: mål och fasteprogram – rapport

Byggd av Codex (planens commits 1–6 + träningsbonusen), slutförd av Claude Code 2026-09-26 (gren `fas-1a`). Plan: `docs/plan/fas1a.md`.

**Ändrat:** mål (fastor per vecka, målvikt) i Profil; tre program på Timer med dagens förslag, paus, byte, avsluta och "klart"; "Schema: 16:8" under pågående fasta; träningsrutan visar bonusen efter taket 1,4×. Mål och program sparas som nya händelser i loggen – inget nytt dataformat, ingen migrering. `js/program.js` ligger i `PRECACHE` (cache-versionen höjs vid publicering).
**Claude Code rättade:** "Fortsätt programmet" syns nu direkt på kortet när programmet är pausat (låg förut bara under ⋯); bekräftelsen vid byte upprepade inte längre rubriken.

**Testat:** 93 enhetstester (92 gröna, 1 "todo" från T-17 som T-18 löser). I 390×844 mot v37 på samma adress (`/qa-main/`): se `docs/qa/qa-fas1a.md`. Rådatan från v37 var byte för byte oförändrad; mål och program överlevde att v37 avslutade, raderade och rensade historiken; två flikar vägrar skriva över; inga konsolfel.
**Inte testat i webbläsaren:** import av fil med program (täcks av enhetstest), riktig midnattsövergång (dagräkningen täcks av enhetstester inkl. sommartid), riktig telefon.
**Risk:** en version äldre än v34 i en gammal flik kan skriva över nyare data (fanns redan).

## Nya UI-texter (beslut 6)
- Profil → Mål: "Mål", "Fastor per vecka", "Inget mål", "Den här veckan: 3 av 5 fastor", "Målvikt (kg, valfri)", "Målvikt måste vara 30–250 kg.", "Källa: …"
- Timer: "📋 Välj program", "Dagens förslag", "Schema valt: 12 h · Dagens förslag", "▶ Starta 12 h fasta", "Den här veckan: 3 av 5 fastor", "Schema: 16:8"
- Panelen: "Välj program", "Starta programmet", "Källor: …", bekräftelse "Byta program?" / "Det nuvarande programmet avslutas." / "Byt program"
- Programkortet: "Dag 9 av 28 · Vecka 2", "· Pausat", "Fasta 14 timmar", "3 av 5 dagar den här veckan", "Fortsätt programmet", "Pausa programmet", "Byt program", "Avsluta programmet", bekräftelse "Avsluta programmet?" / "Programmet avslutas. Dina sparade fastor finns kvar.", "Programmet är klart", "Välj nytt program", "Stäng"
- Träningsrutan: "~X h extra fastaeffekt nu (tak 1,4x)"

## Det här kan Anton se på datorn (förhandsversionen)
1. Profil → nytt kort **Mål**: välj 5 fastor per vecka, skriv en målvikt. Kryssa "ätstörning" i Hälsa → texten under målvikt byts.
2. Timer → **📋 Välj program** → tryck "Kom igång" → "Starta programmet". Överst: "Dag 1 av 28 · Vecka 1 · Fasta 12 timmar", stora knappen säger "Starta 12 h fasta".
3. Tryck **⋯** på programkortet → Pausa, Fortsätt, Byt program, Avsluta.
4. Utan program och med veckomål: raden "Den här veckan: X av 5 fastor" under knapparna på Timer.
5. Starta en 16:8-fasta → rubriken säger "Schema: 16:8" (inte "16h").

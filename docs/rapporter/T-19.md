# T-19 – säkerhetshuvuden

Status: klar på gren `codex/T-19`, för Claude Codes granskning.

- Ny `vercel.json` ger alla sökvägar `X-Content-Type-Options: nosniff`, `Referrer-Policy: strict-origin-when-cross-origin`, `Permissions-Policy: camera=(), microphone=(), geolocation=(), payment=()` och `X-Frame-Options: DENY`.
- `/sw.js` får dessutom `Cache-Control: no-cache` för kontroll av färsk version före återanvändning.
- Ingen CSP, omdirigering eller bygginställning tillagd. Appkod och cache-version oförändrade.
- Syntax kontrollerad mot [Vercels dokumentation](https://vercel.com/docs/project-configuration/vercel-json#headers), läst 2026-09-26.

## Claude Code efter förhandsvisning/publicering
1. Kör `curl.exe -sI https://fastatimer.se/` och kontrollera alla fyra säkerhetshuvudena. Använd förhandsversionens adress före publicering.
2. Kör `curl.exe -sI https://fastatimer.se/sw.js`: samma fyra huvuden och `Cache-Control: no-cache` ska finnas.
3. Kontrollera även `/js/app.js` och `/css/styles.css`, korrekta innehållstyper och att ingen CSP tillkommit.

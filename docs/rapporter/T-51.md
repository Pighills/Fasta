# T-51 – Fastenivå i planerade måltidslägen

Status: klar på gren `codex/T-51`, byggd från granskad `lokal/codex/T-50`.

- Timer: textknappen ”Planera måltid” under Fastenivå öppnar planerat läge.
- Måltidsrutan visar uppskattad tid efter pass, över 24 h från fastans start eller vid explicit planering.
- Inledning visas vid planering/lång fasta; över 24 h visas även befintlig dygnspåminnelse.
- Uppskattningen ligger under vald kategori, uppdateras vid byte och använder `mealPauseHours`.
- Träningsraden döljs efter två timmar med timeruppdateringen, utan ombyggnad av vyn.
- Samma träningsvillkor som modellen: minst 20 min, inte Yoga/Stretch, inget framtida pass.
- Kategoriernas ordning och fria val behålls; inga poäng eller värderingar tillagda.
- Tre saknade texter lades till i `js/data.js`, ordagrant från kunskapsbasen enligt uppgiftens undantag.
- Kunskapsbas, datamodell, cacheversion och produktionsflagga är orörda.

Kontroller: `node --check` på samtliga tre ändrade JS-filer; 191/191 tester gröna; `git diff --check` OK.
Nya tester täcker alla lägen, kategoriändring, kategoriordning, tidsgränser, träningsundantag och flaggan av.
Webbläsare: lokal server på port 3051; 390×844 och 1280×900, vanlig/planerad måltid, efter pass, kategoribyte och flaggan av.
Ingen sidledes överströmning vid 390 px; planeringsknappen är 44 px hög.

Anton kan kontrollera på datorn med Fastenivå på:
1. Timer under aktiv fasta: ”Planera måltid” under baren.
2. Måltidsrutan: byt kategori och se tiden under valet.
3. Vanlig ”Logga måltid” under kort fasta utan pass: ingen förhandsvisning.
4. Logga ett pass på minst 20 min: träningsrad och kortare uppskattad måltidstid.

# T-11 – service worker

Status: klar på gren `codex/T-11`, för Claude Codes granskning. Inget pushat/publicerat.

- Efter 3 sekunders nätväntan används en sparad kopia om den finns. Nätet får fortsätta uppdatera kopian via `waitUntil`.
- Offlinebesök med frågeparametrar får sparad sida eller startsidan. Saknas båda returneras ett uttryckligt nätfel.
- Bara lyckade same-origin-svar för fördefinierade filer sparas. Navigeringens frågeparametrar skapar inga nya cacheposter.
- Relativa precache-sökvägar fungerar även i en undermapp. Cache-versionen är oförändrad enligt uppdraget.
- Alla cache-skrivningar inväntas av `waitUntil`; misslyckad cachelagring blockerar inte nätets svar.

## Kontrollerat
- `node --check sw.js`, `node --check tests/sw.test.mjs`: godkänt.
- `node --test tests/*.test.mjs`: 49 godkända, varav 11 nya service worker-tester med falsk tid.
- Testerna täcker också sena svar, avslutad cache-skrivning, okända filer, subkatalog och origin-kontroll.
- Lokal app startad på 127.0.0.1:5311 och granskad i webbläsaren vid 390×844; även `?utm_source=test` öppnar timern.

## Kvar till Claude Code
- Kontrollera offline efter första besöket, inklusive `?utm_source=x`, med riktig service worker i webbläsaren.
- Kontrollera strypt nät: sparad sida efter cirka 3 s och uppdaterad kopia efter nätets sena svar.
- Kontrollera offline utan sparad fil, 404/500 samt installation under undermapp. Höj cache-versionen vid publicering.
- Installerad telefonapp och notch är inte provade på fysisk telefon.
- Kön är läst men inte ändrad: protokollet anger att Codex bara läser den.

## Anton kan se på datorn efter granskning
1. Timer ser likadan ut vid vanlig öppning.
2. En länk med `?utm_source=test` öppnar samma startsida.
3. Efter första besöket ska startsidan kunna öppnas utan nät.
4. Vid segt nät ska sparat innehåll visas efter ungefär tre sekunder.

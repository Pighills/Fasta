# T-43 – påminnelse vid längre fastor

- Status: klar på gren `codex/T-43`, redo för granskning; stor ändring, väntar därefter på Anton före publicering.
- Timer: 36/48/72 h visar godkänd text före start, både vanlig och bakåtdaterad start. Avbryt och Esc startar inget.
- Löpande fasta: påminnelsen visas under ringen från 24 faktiska fastetimmar (måltidspauser räknas bort).
- OK sparar `startTime` som text i `fasta-langfasta`; samma fasta döljs efter omladdning, ny starttid kan visa rutan igen.
- Hälsoraden visas bara om `profile.health` har ett sant kryssvärde. Hälsosvar kopieras inte.
- Radera all data tar bort den nya kvittensnyckeln. Ingen ändring i `fasta-data`, export/import eller migrering.
- Vid blockerad lagring gäller OK under sidans livstid; efter omladdning kan rutan återkomma.
- Godkända texter kopierade ordagrant från `halsa.langFasta`, `.dygn`, `.profil`.
- Code behöver sätta dessa tre kunskapsbasrutor till inbyggd och fylla i nu/Kod; Codex får inte ändra kunskapsbasen.
- Utseende: befintlig modal och dämpad caution-färg enligt DESIGN.md; ingen ny färgvärld.
- Ingen ny timer/intervall. Befintlig tick uppdaterar bara påminnelsens behållare; befintliga fasbyten behåller sin omritning.
- Syntaxkontroll av alla fyra ändrade JS-filer och nya testfilen OK; 168/168 tester gröna (8 nya).
- Lokalt 390×844 med samma CSP-huvud som Vercel: appstart, 36 h-ruta, Avbryt/Esc/fokus, bakåtdaterad bekräftad start, dygnsruta, OK/omladdning, ny fasta och profilrad testade; 0 konsolfel.
- Knappmått: start/avbryt minst 77×51 px, OK minst 44×44 px; ingen sidledsscroll.
- Automatiska tester täcker även 48/72 h, korta scheman/∞ utan startruta, 24 h-gränsen, blockerad lagring och radering.
- Före-bilder serverades från oförändrad v46 (180c815); efter-bilder från arbetskopian. Alla finns i `docs/design/T-43/`.
- Begränsning: TBT 154 ms från T-09 har inte kontrollmätts; Code behöver jämföra mobilprestanda vid granskning. Ingen prestandaförsämring är kvantitativt verifierad här.
- Riktig telefon, installerad app/notch/offline och fysisk skärmläsare har inte testats. Dialogens befintliga fokusfälla/Esc återanvänds.
- Cache-versionen lämnas oförändrad enligt Codex-flödet; Code höjer vid publicering. Inga nya appfiler behöver PRECACHE.
- Kön i huvudmappen lämnas till Code enligt regeln att Codex bara läser den.

## Anton kan kontrollera på datorn
- Timer → Testa ett fasta-schema → 36h, 48h eller 72h → Starta: informationsrutan visas först.
- Välj Avbryt eller Esc: ingen fasta startar. Starta fastan behåller vald bakåtdatering.
- Timer → löpande fasta → bakåtdatera mer än ett dygn: påminnelsen syns under ringen; OK döljer den.
- Kryssa i en ruta i Profil → Hälsa och säkerhet: båda påminnelserna får hänvisningen till Profil.

Nästa: Code granskar, kontrollmäter mobilprestanda och uppdaterar kunskapsbas/kö; Anton godkänner publicering som fasta-v47.

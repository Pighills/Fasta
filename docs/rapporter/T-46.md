# T-46 – Delningsbild för länkar

Klar på gren `codex/T-46`, byggd från färdiga `codex/T-45` (31f6a20).
Liten ändring, redo för Code-granskning i paketet fasta-v48.

- Ny PNG 1200×630, 41 672 byte: svart, guld, lokalt Outfit och en stiliserad timerring.
- Exakt beställt innehåll; inga nya hälsopåståenden.
- HTML-källa: `docs/design/T-46/bild.html`. Skapad med Playwright och installerad Edge; kopia i `docs/design/T-46/efter.png`.
- Båda sidornas head har bild, storlek, svensk alternativtext och Twitter-kort med stor bild.
- Integritetssidans befintliga titel och beskrivning kopierade till Open Graph.
- Ingen ändring i appvyer, användardata, CSP eller service worker. Code höjer cache vid publicering.
- Syntaxkontroll av ändrad testfil: grön. Alla 171 tester gröna, diff utan whitespace-fel.
- Lokal server: appstart i 390×844, app synlig och inga JavaScript-fel. Integritetssidan laddar och bilden ger 200.
- Bilden öppnad och visuellt kontrollerad: texten ryms, korrekt typsnitt och färger.
- Faktiska delningar i Messenger, sms och sociala medier kan kontrolleras efter publicering; tjänsterna kan behålla äldre förhandsbilder.
- Kön läses bara av Codex enligt arbetsflödet; Code uppdaterar status vid granskning.

Anton kan kontrollera på datorn:
1. Öppna `docs/design/T-46/efter.png`: stor FASTA-rubrik och guldring.

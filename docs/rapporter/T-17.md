# T-17 – tester av export och import

Status: klar på gren `codex/T-17`, för Claude Codes granskning. Bara tester och rapport.

- 13 nya tester anropar `exportData`, `importData` och `undoImport` med falsk DOM och localStorage; riktig appkod körs utan omskrivning.
- Täcker export/import med aktiv fasta, profil och loggar, import av v0/v1/v2, avbruten import, Ångra import, nyare dataversion, trasig JSON, främmande filer och misslyckad backuplagring.
- Importerad `<script>`-text bevaras som data och kontrolleras via `esc` för säker textvisning.

## Fynd – ofullständig v2-fil accepteras (bör prioriteras)
- Reproduktion: importera `{"app":"FASTA","schemaVersion":2,"active":null,"profile":{}}` och bekräfta.
- Förväntat: filen vägras eftersom `events` saknas; nuvarande data behålls.
- Faktiskt: `migrate` godtar den saknade listan och `normalize` gör den tom. Profil, aktiv fasta och historik ersätts av tom data.
- Tidigare data sparas i importens säkerhetskopia, så Ångra import kan återställa den. Testet använder bara konstgjorda data.
- Testet är markerat `todo` enligt uppdraget och misslyckas fortfarande på den önskade kontrollen. Ingen appkod rättad.
- Föreslagen separat uppgift: validera obligatoriska listfält för respektive filversion innan import erbjuds; äldre v0/v1-filer ska fortsatt kunna migreras.

# T-38 – Känsla, animationer och appikoner
Status: klar på gren `codex/T-38`, från granskade `lokal/codex/T-37`.

- Flikarnas innehåll tonar in på 180 ms. Inga fördröjningar, loopar eller studs.
- Rutor glider upp 16 px på 240 ms i stället för att zoomas. Reducerad rörelse ger enbart 120 ms toning; övergångar stängs av som tidigare.
- Hover-effekter gäller bara när enheten stöder hover. Befintlig tryck- och fokusåterkoppling bevarad; guldknappar får diskret ljushetsändring vid tryck.
- theme-color i index.html och manifest.json är nu #0a0a0a, för mörk Android-statusrad. Startbakgrunden var redan svart.
- Knappskuggan följer redan DESIGN.md: 0 2px 12px rgba(200,168,78,0.18), därför oförändrad.
- Befintliga ikoner behålls: svart/guld, 180/192/512 px. Guldmotivet i 512-ikonen ryms inom maskable-säkerhetscirkeln (radie 169,4 px av tillåtna 204,8).
- Ingen ändring av hälsotexter, sparformat, JavaScript eller cache-version. Inga nya appfiler att lägga i PRECACHE.
- Impeccable (animate/craft-floor) och frontend-skill använda inom befintligt designspråk; inga program eller hooks körda.
